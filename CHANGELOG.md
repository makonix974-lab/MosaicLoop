# Changelog

## v0.2.0 (refactor `refactor/v0.2-slim`)

A focused slim-down. Same core function (sync N cams, render a grid),
fewer LOC, fewer deps, no hangs, real tests.

### Bug fixes
- **Stderr deadlock** (the original v0.1 freeze): every long-running
  FFmpeg `Popen` now redirects stderr to a tempfile instead of leaving
  `stderr=PIPE` undrained. Read on error only.
- **240 fps trap**: grid composition now sets `-r {output_fps}` so source
  framerate doesn't propagate (240 fps rushes were re-encoding 8× too
  many frames).
- **Apply-offsets corruption**: the v0.1 padding step could produce 1.7 GB
  MP4s with no `moov` atom on long rushes. The whole step is gone.

### Added
- `src/utils/ffmpeg_run.py` — single canonical `run_ffmpeg()` with
  progress bar, timeout, stderr-to-tempfile.
- `src/cache.py` — `SessionCache` skipping proxy + sync when inputs are
  unchanged. Cold run 3.5 s → warm run 1.1 s on fixtures (3.2× speedup).
- `src/models.py` — unified `Clip` + `ClipMetadata` dataclasses.
- `cli/main.py auto --no-cache` flag.
- `tests/test_integration.py` — 5 real integration tests with synthetic
  fixtures (auto-generated by `tests/conftest.py`).
- `tests/test_sync.py`, `test_models.py`, `test_composer_filters.py` —
  35 unit tests.
- `docs/BASELINE.md` — v0.1 → v0.2 metrics tracking.
- `docs/ARCHITECTURE.md` — pipeline diagram + module responsibilities.

### Changed
- Pipeline collapses from 4 steps to 3: per-clip time pads now live
  inside the grid's `filter_complex` (`tpad` for video, `adelay` for
  audio). Zero intermediate files on disk.
- `video_analyzer.py`: 1167 → 228 LOC. Kept energy + BPM + onsets +
  segmentation. Dropped MFCC, chroma, key/mode, scene detection,
  motion estimation, similarity matching.
- `proxy.py`: 423 → 175 LOC. Removed `restore_from_proxy`,
  `EditDecisionList`, `ExportEngine` (all dead code).
- `pipeline.py`: removed `_step_apply_offsets`,
  `_validate_video_file`, `_cleanup_corrupted_files`, `_step_compose`.
- `requirements.txt`: removed `scipy`, `soundfile`, `pydub`,
  `ffmpeg-python`, `tqdm`, `scenedetect`, `opencv-python`. Kept
  `numpy`, `librosa`, `click`.

### Removed (archived to `archive/v0.1/`)
- `src/composer/smart_composer.py` — based on a faulty premise (audio
  energy is identical across multi-cam clips of the same performance,
  so "smart" switching degenerates to picking the first match).
- `gui/` PyQt6 frontend — to be rebuilt from scratch in v0.3.
- `cli/rush_sorter.py` — broken at v0.1 (NameError), out of scope.
- `cli/test_full_pipeline.py` — superseded by `tests/test_integration.py`.
- `src/record/`, `src/export/` — empty placeholder modules.
